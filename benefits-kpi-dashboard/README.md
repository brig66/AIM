# Benefits Command Center (Coble Cravens)

Private KPI dashboard for an independent Texas group-benefits broker.

- Live page: https://claude.ai/artifact/Agy51spYQWmutacmiE5LdF
- Source: `dashboard.html` (publish this file to update the page)
- Weekly market refresh: Routine "Benefits Dashboard Weekly Market Refresh" (Mondays 6:52 AM Central); its instructions are in `weekly-refresh-prompt.md`

Sections: Overview KPIs, Book of Business, Renewals and plan-year transition checklist, Plan Library and side-by-side compare, What-If modeler with ACA affordability check, Present to Client view, Texas Market Intel (FRED/BLS, KFF, IRS), and an AI Assistant.

Privacy: groups are stored by client code only. The page blocks Social Security numbers, emails, phone numbers and health-condition wording before saving or sending to the AI Assistant.
