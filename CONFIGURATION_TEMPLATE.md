## HELPFUL TIPS

### Meta Description Writing Tips
- Use primary keyword near beginning
- Make it click-worthy (call-to-action helps)
- Include location if B2B local
- Avoid keyword stuffing
- Make each page unique if possible

### LinkedIn Company Page
- If you don't have one, create at linkedin.com/company/
- Must be fully completed before adding URL
- Use exact URL from company page

### Google Business Profile
- If you don't have one, claim at google.com/business/
- Complete all fields before adding URL
- Verify ownership to enable reviews
- Same address as website's official address

### Logo URL Format
- Must be direct image link (ends in .png, .jpg, .gif)
- Cannot be a web page
- Use HTTPS (not HTTP)
- Minimum 112x112 pixels recommended
- Maximum 1200x1200 pixels

### Founding Date Format
- Use YYYY-MM-DD format exactly
- Example: 2001-06-15 for June 15, 2001
- Required for schema completeness
- Helps with entity age signals

## TROUBLESHOOTING CONFIGURATION

### "This field is required"
- Don't leave required fields blank
- Check spelling and formatting
- Copy from this template to avoid typos

### "Invalid URL format"
- Remove "http://" or "https://" prefix before re-entering
- The field adds it automatically
- Use complete URLs (include www if applicable)

### Can't find LinkedIn Company Page URL
- Go to linkedin.com and search your company
- Click the company name
- Copy URL from address bar
- Should be: https://www.linkedin.com/company/[name]/

### Can't find Google Business Profile
- Search your business name on Google Maps
- Click your business profile
- Copy URL from address bar
- Should be: https://www.google.com/maps/place/[name]/

### Meta Description Too Long
- Count characters (aim for 150-160)
- Remove less important words
- Keep it compelling and specific
- The field shows character count

## WHAT HAPPENS AFTER SAVING

Once you click "Save Settings":

1. ✅ Plugin stores your configuration
2. ✅ Creates version snapshot for undo
3. ✅ Generates schema.org markup
4. ✅ Injects metadata to pages
5. ✅ Starts tracking changes
6. ✅ Shows status in dashboard

You can:
- ✅ View page source to see schema
- ✅ Check Google Rich Results Test
- ✅ Wait 24-48 hours for search snippet update
- ✅ Return to settings to make changes anytime
- ✅ Click "Undo" if you change anything
